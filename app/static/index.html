1. Cumulative Exposure Risk Function

      

        Total risk R(t) at timestamp t is computed as a weighted sum over four normalized dimensions:
      


      

        R(t) = α · S(t) + β · C(t) + γ · L(t) + δ · D(t)
      


      

        

          α · S(t) (α = 0.35)
          Payload sensitivity score from classes S0 (0.0) through S4 (1.0).
        

        

          β · C(t) (β = 0.30)
          Cumulative historical exposure with logistic saturation: C(t) = 1 - e^(-λ Σ w_i).
        

        

          γ · L(t) (γ = 0.20)
          Graph connectivity score linking customer identifiers to external entities.
        

        

          δ · D(t) (δ = 0.15)
          Destination risk score (Core Banking = 0.0, Blacklisted Partner = 1.0).
        

      

    


    
    

      
2. Key Management Hierarchy (HKDF-SHA-256)

      


Master Key (256-bit Hardware Key Storage)
   │
   ├── HKDF-Expand(MasterKey, "tenant:{tenant_id}") ───────► Tenant Key
   │                                                             │
   │                                                             ├── HKDF-Expand(TenantKey, "purpose:{purpose}") ──► Purpose Key
   │                                                             │                                                        │
   │                                                             │                                                        └── HKDF-Expand(PurposeKey, "epoch:{epoch_id}") ──► HMAC Token Key
   │                                                             └── HKDF-Expand(TenantKey, "aes_encryption") ────► AES-256-GCM Key
   └── HKDF-Expand(MasterKey, "audit_integrity") ──────────► Audit Trail Hash Key
